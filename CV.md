# CV Description

## Short version (for a projects list / one-liner)

> CPU Scheduling Simulation — Java, Concurrency — Extended a concurrent producer/consumer coursework codebase to implement and compare FCFS and SJF scheduling, measuring waiting, turnaround, and response time under varying system load.

## CV bullet points (pick 3–4)

- Extended a provided concurrency-based simulation framework (patrons, orders, a shared queue, and a single server) into a runnable model of process scheduling, mapping arrivals to process arrivals and units of work to CPU bursts.
- Implemented First Come First Served (FCFS) scheduling using a FIFO `LinkedBlockingQueue`, and Shortest Job First (SJF) scheduling using a `PriorityBlockingQueue` ordered by execution time.
- Instrumented the simulation to collect standard OS performance metrics — waiting time, turnaround time, and response time — across scheduling strategies.
- Analysed how each algorithm's performance characteristics diverge as system load increases, comparing FCFS's fairness against SJF's throughput advantage.
